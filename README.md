# Syncly

**Syncly** — Telegram-бот для учёта рабочего времени, управления сменным графиком и поиска общих свободных дней с друзьями или коллегами.

## О проекте

Syncly помогает пользователям вести собственный график работы, отслеживать количество отработанных часов и находить дни, когда несколько человек одновременно свободны.

Вместо таблиц и ручного подсчёта вся информация доступна прямо в Telegram.

## Основные возможности

### 1. Личный график
- Добавление рабочих смен.
- Указание даты, времени начала и окончания смены.
- Просмотр графика на неделю и месяц.
- Редактирование и удаление смен.
- Отметка выходных и нерабочих дней.

### 2. Учёт рабочего времени
- Автоматический подсчёт отработанных часов.
- Статистика за неделю и месяц.
- Подсчёт общего количества смен.
- Просмотр истории отработанного времени.

### 3. Совместные выходные
- Добавление друзей или коллег.
- Просмотр графика другого пользователя (с его разрешения).
- Поиск общих свободных дней.
- Возможность найти дату, когда несколько пользователей могут встретиться.

## Как это работает

1. Пользователь запускает Telegram-бота.
2. Добавляет свои рабочие смены.
3. Бот автоматически рассчитывает рабочее время.
4. Пользователь добавляет друга или коллегу.
5. Syncly сравнивает расписания и показывает общие свободные дни.

## MVP

Первая версия проекта включает:

- Регистрацию пользователей через Telegram.
- Создание и управление рабочими сменами.
- Просмотр личного календаря.
- Автоматический подсчёт отработанных часов.
- Добавление пользователей в список контактов.
- Поиск совпадающих свободных дней.

## Дальнейшее развитие

Возможные функции будущих версий:

- Групповые календари.
- Статистика рабочего времени за произвольный период.
- Учёт переработок.
- Уведомления о предстоящих сменах.
- Экспорт расписания.
- Интеграция с Google Calendar.
- Совместное планирование мероприятий.

## Цель проекта

Создать простой инструмент, который избавляет от ручного ведения графика, помогает контролировать рабочее время и упрощает планирование совместного отдыха.
